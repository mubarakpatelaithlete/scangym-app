# ScanGym Clone

Basic project structure for the ScanGym app clone.

## Project Layout

- `src/` - Source code
  - `api/` - Backend services (Node.js)
  - `mobile/` - React Native / Flutter application
  - `iot/` - QR/Access control logic
- `docs/` - Documentation
- `tests/` - CI/CD scan scripts

## Getting Started

Follow the instructions in the `docs/` folder to set up the environment.
