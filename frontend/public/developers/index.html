2. Call the API

Send your key in the X-API-Key header. Base URL: https://www.scangym.com/api/v1

fetch('https://www.scangym.com/api/v1/reels?limit=10', {
  headers: { 'X-API-Key': 'sg_live_YOUR_KEY' }
}).then(r => r.json()).then(console.log);
curl -H "X-API-Key: sg_live_YOUR_KEY" https://www.scangym.com/api/v1/products

Endpoints

GET /reelsVideo feed. limit, offset, category
GET /categoriesReel categories
GET /productsDigital products in the Shop. category, q, limit
GET /products/:idOne product
GET /gymsGyms near lat & lng, or by text query

Limit: 60 requests per minute per key (HTTP 429 when exceeded). Read-only. Works from browsers (CORS enabled). Prefer calling from your server so your key stays private.
